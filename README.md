# Tiny Terrains

**Merge · Plan · Score**: a cozy low-poly 3D merge puzzle for phones, tablets and desktop browsers.

▶ **Play:** https://pixel-pusher-hub.github.io/little-nooks/

On iPhone, open the link in Safari, then tap **Share → Add to Home Screen** to install it like an app. It keeps working offline after the first visit.

No ads, no purchases, no accounts.

This repository only contains the built game that GitHub Pages serves.
